# Ctrl+V 秒传路过图床

**中文** | [English](README.en.md)

在任意网页上按 <kbd>Ctrl</kbd>+<kbd>V</kbd>，剪贴板里的截图自动上传到[路过图床（imgchr.com）](https://imgchr.com/)，链接立刻插入当前输入框——不需要打开图床的标签页，不需要 API key。

![封面](docs/social-preview.png)

## 它解决什么问题

- **能贴图的地方（富文本编辑器）**：扩展完全不干涉，页面自己的粘贴逻辑一步不少。
- **只能填文字的地方（普通 `input` / `textarea`）**：浏览器本来只能贴出文件名。扩展把图片交给后台一个隐藏的 imgchr 页面上传，然后把链接插进去。

## 功能

- 全局截图粘贴上传，支持 6 种输出格式：Markdown、源文件直链、图片网页、HTML、BBCode、Markdown 带跳转（缩略图）。
- 可选定时删除：1 小时 / 6 小时 / 1 天 / 7 天后自动删图，优先用图床自己的 `expiration` 字段，不支持时退化为本地待删队列 + 后台定时器执行。
- 内置额度保护：按服务条款的上限（60 张/小时）本地计数，超限直接拒绝发请求。
- 首次使用前会展示图床服务条款的内容红线并要求确认。
- 上传结果以卡片形式展示，保留全部格式的一键复制按钮。

## 工作原理

imgchr 免费账号领不到 API key，跨站上传必须由一个真正的 imgchr 文档在同源环境里发请求。扩展按需拉起一个隐藏的 offscreen 文档（内嵌不可见的 imgchr iframe），由它完成上传，任务结束且空闲后自动销毁：

```
网页 Ctrl+V ──▶ content.js ──▶ background (service worker)
                                   │ 按需创建
                                   ▼
                          offscreen 文档 ◀── 内嵌隐藏 iframe（imgchr.com）
                                   │              由 imgchr-frame.js 同源 fetch 上传
                                   ◀── 结果原路返回 ──▶ 插入输入框 / 复制到剪贴板
```

`auth_token` 和登录 cookie 全程留在 imgchr 自己的文档里，不跨出、不重放。

**刻意不做的事**：抓取 imgchr 首页、把一次性的 `auth_token` 抠出来跨站重放。那是站方的 CSRF 防护，绕开它等于破解安全控制，即使是给自己的账号传图也不行。这也是本项目不采用「直接调上传接口」这类方案的原因。

## 前置要求：登录路过图床

**使用前请先注册并登录 [imgchr.com](https://imgchr.com/login)。**

扩展的上传通道必须处于登录状态才能工作：访客（未登录）上传的图片 7 天后会被图床删除，因此扩展检测到未登录时会直接拒绝上传，并在提示卡片上给出「去登录 imgchr」按钮。登录一次即可，之后隐藏通道会复用同一会话，不需要重复登录。

## 安装

要求 Chrome 116 及以上（用到 offscreen documents API）。

1. 下载本仓库（Code ▸ Download ZIP，或 `git clone`），解压。
2. 打开 `chrome://extensions`，右上角开启「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压出来的文件夹（里面直接就是 `manifest.json`）。
4. （可选）到扩展详情里给本扩展开「允许访问文件网址」，并按 `background.js` 顶部的说明配置自更新路径，改代码后可自动重载。

## 使用

1. 首次使用先在扩展的「选项」页确认服务条款。
2. 任意网页上截图（任意截图工具，图片进入剪贴板即可），在输入框里按 <kbd>Ctrl</kbd>+<kbd>V</kbd>。
3. 上传完成后链接自动插入；若关闭了自动插入，则复制到剪贴板。

## 隐私

- 本扩展不收集任何数据，没有统计、没有上报。
- 图片只从你的浏览器发往 imgchr.com。
- 设置存储在本地 `chrome.storage.local`。

## 额度与内容红线

路过图床服务条款（2026-06-05 修订）与「随手截图」最相关的几条：

- 上传频率上限 60 张/小时；登录用户单张 5 MB。
- 禁止含二维码的图片；禁止卡通漫画 / ACG / 二次元 / 动漫游戏画面；禁止未经授权的影视截图或封面。
- 免费套餐仅限个人非商用。

违规会被删除账号下全部图片并封号封 IP，请自己把关。

## 目录结构

```
├── manifest.json      MV3 清单
├── content.js         全页面粘贴监听 + 上传结果卡片
├── background.js      offscreen 文档生命周期 + 任务路由 + 定时删除
├── offscreen.html/js  隐藏通道页（内嵌 imgchr iframe）
├── imgchr-frame.js    在 imgchr 文档内执行的同源上传/删除
├── options.html/css/js 设置页
├── _locales/          中文 + 英文文案（跟随浏览器语言）
└── docs/              封面图
```
