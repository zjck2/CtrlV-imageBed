不需要 API key，也不需要打开 imgchr 标签页。跨站上传由扩展后台一个隐藏的 imgchr 页面 执行（用时自动创建、空闲自动销毁），auth_token 和登录 cookie 全程留在 imgchr 自己的页面里。

不干涉规则

监听在页面脚本运行之前就位（捕获阶段），但只旁听、不拦截——页面自己的粘贴逻辑一步不少。 两种情况完全不干涉：光标在富文本（contenteditable）编辑器里（它自己能收图），或页面自己接管了 这次粘贴（preventDefault）。其余情况下——普通 input / textarea， 或光标不在输入区——才会上传。复制文字永远不会触发它。
